# MultiDayExpenseReport
Ask the user how many days to log, then for each day ask for a date and repeatedly ask for a category and amount (comma-separated) until they type 'done' for that day. Print each day's total spending and the set of all unique categories used across every day.
<br>
Topics Covered
1. input() — taking user input.
2. int() — converting input into an integer.
3. float() — converting expense amounts into decimal numbers.
4. def — defining a function.
5. for loop — processing multiple days.
6. while True — repeatedly accepting expenses until the user types done.
7. if and break — stopping the loop when the user types done.
8. Dictionaries (dict) — storing each date and its total expenses.
9. Sets (set) — storing unique expense categories.
10. split() — separating the category and amount using a comma.
11. strip() — removing extra spaces.
12. lower() — accepting done regardless of capitalization.
13. += — adding each expense to the daily total.
14. set.add() — adding categories without duplicates.
15. dict.items() — accessing dates and their totals.
16. F-strings — formatting the expense report.
17. :.2f — displaying amounts with two decimal places.
